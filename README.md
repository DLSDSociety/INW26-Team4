# E-Commerce Web Application (MERN)
 
Live demo: https://your-store.netlify.app
API:       https://your-api.onrender.com
 
## Features
  - Auth (JWT, roles), product search/filter/sort,
    cart, orders, Razorpay payments, reviews,
    admin dashboard with analytics
 
## Tech Stack
  MongoDB · Express · React (Vite) · Node.js
  Redux Toolkit · Tailwind · Recharts · Jest
 
## Screenshots
  (home, product, cart, admin dashboard)
 
## Getting Started
  1. git clone <repo>
  2. backend:  cd backend && npm install
  3. frontend: cd frontend && npm install
  4. copy .env.example to .env in each, fill values
  5. backend:  npm run dev   (port 5000)
  6. frontend: npm run dev   (port 3000)
